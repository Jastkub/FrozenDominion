# Iron's Spellbooks: Frozen Dominion

Eight ice spells for [Iron's Spells 'n Spellbooks](https://www.curseforge.com/minecraft/mc-mods/irons-spells-n-spellbooks),
from the world of [Frozen Dominion](https://www.curseforge.com/minecraft/mc-mods/velkhar-the-frozen-dominion) - and the
Priestess's Rime Breviary. Works on its own with Iron's Spells; with Frozen Dominion installed, its scrolls turn up in
the citadel's chests and its spells are bound into the citadel's weapons.

Branch `addon-iss-1.21.1`. To build, put the Iron's Spells 'n Spellbooks (and, for 1.20.1, Iron's Lib) jars for this version in
`libs/` and run `./gradlew build`.
